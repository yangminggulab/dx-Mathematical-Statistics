## 必记公式索引

```
顺序统计量密度    f_{(r)}(x) = r·C(n,r)·F^{r-1}·[1-F]^{n-r}·f(x)
联合分布函数      F_{U,V}(x,y) = [F(y)]^n − [F(y)−F(x)]^n,  x≤y
U(0,θ)矩公式     E[X_{(n)}^k] = nθ^k/(n+k)
正态三定理        X̄~N(μ,σ²/n)；(n-1)s²/σ²~χ²(n-1)；X̄⊥s²
C-R 下界          Var(ĝ) ≥ [g'(θ)]²/[n·I(θ)]
Delta 方法        √n·(h(θ̂)−h(θ)) →^L N(0,[h'(θ)]²·V(θ))
MSE 分解          MSE = Var + 偏差²
```
