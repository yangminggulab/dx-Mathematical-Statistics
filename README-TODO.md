6/24 后：字节数据分析面试 — A/B Test 与数理统计对照
==============================================================

A/B Test 本质就是假设检验的工业落地，数理统计每个模块都有对应。

--------------------------------------------------------------
模块对照
--------------------------------------------------------------

  假设检验（能力四）
    H₀: μ_A = μ_B（两组无差异）
    H₁: μ_A ≠ μ_B（双侧）或 μ_A > μ_B（单侧，看业务方向）
    统计量：Z = (X̄_A - X̄_B) / √(σ²_A/n_A + σ²_B/n_B)
    大样本下 Z ~ N(0,1)（渐近正态保证）

  两类错误（四一节）
    α = P(拒绝H₀ | H₀为真) = 显著性水平，通常取 0.05
    β = P(接受H₀ | H₁为真) = 漏检率
    Power = 1 - β = 检验功效，越高越好

  样本量计算
    n 越大 → 渐近方差 σ²/n 越小 → 检验越灵敏
    给定 α、Power、最小可检测效果量 → 反推 n
    字节面试高频考点：为什么要提前算样本量？

  置信区间（能力三）
    效果量 CI = (X̄_A - X̄_B) ± z_{α/2} · SE
    CI 不含 0 ↔ 拒绝 H₀（与假设检验等价）
    面试常问：p-value 和 CI 哪个更有信息量？（CI 更好，给出了范围）

  渐近正态（能力二）
    大样本下点击率、转化率等比例指标 ~ N(p, p(1-p)/n)
    这就是为什么 A/B Test 要求样本量足够大才能用 z 检验

  MLE（能力一）
    模型参数估计（如 logistic regression 估计转化率）
    字节广告/推荐系统后端大量用 MLE

--------------------------------------------------------------
面试高频问题 & 答题框架
--------------------------------------------------------------

  Q1: 如何判断一个 A/B 实验是否显著？
  → 计算 z 统计量 → 对比 z_{α/2} → 或看 p-value < α

  Q2: 实验跑了 3 天 p=0.04，能上线吗？
  → 不一定：样本量够吗？有没有 novelty effect？SRM 检查了吗？

  Q3: 为什么不能边看结果边决定停止实验？
  → 多次检验膨胀 α（多重检验问题）→ 需要 sequential test 或预设样本量

  Q4: A/A Test 是什么，为什么做？
  → 两组都是 A，验证随机分组是否均匀（SRM 检测）

  Q5: 效果显著但业务不上线，可能是什么原因？
  → 统计显著 ≠ 实际显著；效果量太小不值得工程成本
