## 1. UMVUE 理论

**问题所在**：Lehmann-Scheffé 定理（完备充分统计量→UMVUE）的 dxtips 几乎空白。只知道结论，不知道怎么判断一个统计量是否"完备"。考试遇到变体（换一个分布）时容易不会下手。

**需要补的内容**：
- 完备统计量的定义：对任意函数 $g$，若 $E_\theta[g(T)] = 0\ \forall\theta$ 能推出 $P_\theta(g(T)=0)=1$，则 $T$ 完备
- 指数族的充分完备统计量是 $T(X) = \sum t(X_i)$（记住这个结论）
- UMVUE 充要条件：与所有零无偏估计正交，即 $E_\theta[\delta(X)\delta_0(X)] = 0$

**对应题目**：
- 第七周 homework [11]：泊松分布，$\bar{X}$ 是 UMVUE，$\tilde\lambda^2$ 不是（要搞清楚为什么）
- 第七周 homework [7]：$\bar{X}$ 是最优线性无偏估计（BLUE），与 UMVUE 的区别

## 2. C-R 下界的适用边界

**问题所在**：正则条件四条没有自己的判断语言，特别是「支撑集不含参数」这一条——均匀分布 $U(0,\theta)$ 违反这一条，C-R 下界对它无效，但笔记里没有标记。

**需要记住的判断规则**：

| 分布 | 是否满足正则条件 | 原因 |
|------|----------------|------|
| 正态 $N(\mu,\sigma^2)$ | 满足 | 支撑集 $\mathbb{R}$ 与参数无关 |
| 指数 $E(\lambda)$ | 满足 | 支撑集 $(0,\infty)$ 与参数无关 |
| 均匀 $U(0,\theta)$ | **不满足** | 支撑集 $(0,\theta)$ 含参数 |
| 均匀 $U(\theta-\frac{1}{2},\theta+\frac{1}{2})$ | **不满足** | 支撑集含参数 |

**对应题目**：后期 homework [1]（证明 Fisher 信息量两个等价公式），要能说明证明需要哪些正则条件。

## 3. 顺序统计量雅可比换元策略

**问题所在**：dxtips 里写了「T 的选取是任意的，能和 R 凑出 V 就行」，说明换元时辅助变量的选取还不够确定，依赖提示而非原则。

**需要记住的原则**：
- 求 $R = X_{(n)} - X_{(1)}$ 的分布时，令 $T = X_{(1)}$（或任意一个），$R = V - T$
- 雅可比行列式 $|J| = |\partial(u,v)/\partial(t,r)|$，换元后对 $T$ 积分得 $f_R(r)$
- 换元策略：**新变量组必须能反解出旧变量组**，选谁做辅助变量只影响积分复杂度，不影响结果

**对应题目**：第二次作业 [4]（求 $R = X_{(n)} - X_{(1)}$ 的分布）

## 4. 渐近理论（相合性 / 渐近有效性）

**问题所在**：第三章后半段（MLE 相合性条件、Delta 方法、渐近相对效率）的 dxtips 几乎空白，只转述了定理，没有自己的理解。

**需要能说出来的核心直觉**：
- **相合性**：$n\to\infty$ 时估计量依概率→真值。矩估计量由大数定律保证相合
- **渐近正态性**：$\sqrt{n}(\hat\theta - \theta) \xrightarrow{L} N(0, 1/I(\theta))$，MLE 在正则条件下达到 C-R 下界
- **Delta 方法**：$h(\hat\theta)$ 的渐近方差 $= [h'(\theta)]^2 \cdot 1/I(\theta)$，就是复合函数求导
- **渐近效率**：两个估计量渐近方差之比，比值越小说明用更少样本能达到相同精度

**对应题目**：第三章末尾定理 3.4.5, 3.4.6, 3.4.7，结合正态均值估计的例子理解

## 6. 双参数 MLE 的复合情形

**问题所在**：双参数指数分布（第五周 [10]）做题时需要「先固定一个参数对另一个优化」，这个两步优化策略当时是做到一半才明白的（dxtips 写了「我明白了」）。考试如果再遇到类似结构可能还会卡。

**通用策略**：
1. 写出似然函数，看对哪个参数是单调的（没有驻点）
2. 单调参数在约束范围的边界处取最大值（如 $\hat\alpha = X_{(1)}$）
3. 代入后对另一个参数求导令其为零

**易混点**：均匀分布 MLE（任意区间内都是最大值）和双参数指数（边界处取最大值）看起来相似，但机制不同——前者是 $L=1$ 的区间，后者是指数部分单调。
