1. UMVUE 理论
==============================================================

问题所在：Lehmann-Scheffé 定理（完备充分统计量→UMVUE）的 dxtips 几乎空白。
只知道结论，不知道怎么判断一个统计量是否"完备"。考试遇到变体时容易不会下手。

需要补的内容：

- UMVUE 充要条件：与所有零无偏估计正交，即 Eθ[δ(X)δ₀(X)] = 0

2. C-R 下界的适用边界
--------------------------------------------------------------

问题所在：正则条件四条没有自己的判断语言，特别是「支撑集不含参数」这一条。
均匀分布 U(0,θ) 违反这一条，C-R 下界对它无效，但笔记里没有标记。

判断规则：

  分布                        是否满足正则条件   原因
  -----------------------------------------------------------
  正态 N(μ,σ²)               满足              支撑集 R 与参数无关
  指数 E(λ)                  满足              支撑集 (0,∞) 与参数无关
  均匀 U(0,θ)                不满足            支撑集 (0,θ) 含参数
  均匀 U(θ-1/2, θ+1/2)      不满足            支撑集含参数

对应题目：后期 [Fisher-1]（证明 Fisher 信息量两个等价公式，需说明正则条件）

3. 顺序统计量雅可比换元策略
--------------------------------------------------------------

问题所在：dxtips 里写了"T 的选取是任意的，能和 R 凑出 V 就行"，
说明换元时辅助变量的选取还不够确定，依赖提示而非原则。

需要记住的原则：
- 求 R = X_(n) - X_(1) 的分布时，令 T = X_(1)，R = V - T
- 雅可比行列式 |J| = |∂(u,v)/∂(t,r)|，换元后对 T 积分得 f_R(r)
- 换元策略：新变量组必须能反解出旧变量组，选谁做辅助变量只影响积分复杂度

对应题目：第二次作业 45[4]（求 R = X_(n) - X_(1) 的分布）

4. 渐近理论（相合性 / 渐近有效性）
--------------------------------------------------------------

问题所在：第三章后半段（MLE 相合性条件、Delta 方法、渐近相对效率）的 dxtips
几乎空白，只转述了定理，没有自己的理解。

需要能说出来的核心直觉：
- 相合性：n→∞ 时估计量依概率→真值。矩估计量由大数定律保证相合
- 渐近正态性：√n(θ̂ - θ) →L N(0, 1/I(θ))，MLE 在正则条件下达到 C-R 下界
- Delta 方法：h(θ̂) 的渐近方差 = [h'(θ)]² · 1/I(θ)，就是复合函数求导
- 渐近效率：两个估计量渐近方差之比，比值越小说明用更少样本能达到相同精度

对应题目：8周[9][10][12]，结合正态均值估计的例子理解

5. 假设检验后半段（UMP / 拟合优度）
--------------------------------------------------------------

问题所在：4.4（UMP）和 4.5（拟合优度）几乎没有 dxtips，如果出题会完全没感觉。

UMP 需要记的：
- NP 引理：拒绝域形如 {L(θ₁)/L(θ₀) > k}，即似然比检验
- 单调似然比族：T(X) 是充分统计量，可以用 T 构造 UMP
- 单侧假设（H₁: θ > θ₀）有 UMP；双侧一般没有

拟合优度需要记的：
- Pearson χ² = Σ(nⱼ - npⱼ)² / (npⱼ)  →L  χ²(M-1)
- 参数未知时先 MLE 估计，每估一个参数自由度减一：χ²(M-1-k)
- 使用条件：每格期望频数 npⱼ ≥ 5
- PP 图对中部敏感，QQ 图对尾部敏感（实际中更常用 QQ 图）

对应题目：4.4节{1}{2}{3}[5][6][7]，12周[1][2][extra]

6. 双参数 MLE 的复合情形
--------------------------------------------------------------

问题所在：双参数指数分布（MLE[10]）做题时需要「先固定一个参数对另一个优化」，
两步优化策略当时做到一半才明白。

通用策略：
  1. 写出似然函数，看对哪个参数是单调的（没有驻点）
  2. 单调参数在约束范围的边界处取最大值（如 α̂ = X_(1)）
  3. 代入后对另一个参数求导令其为零

易混点：均匀分布 MLE（任意区间内都是最大值）和双参数指数（边界处取最大值）
看起来相似，但机制不同——前者是 L=1 的区间，后者是指数部分单调。
